# Demonstration scenarios

Two ways to demonstrate: a **live UI walkthrough** (about 6 minutes) and the **scripted, reproducible results**
(`DEMO_RESULTS.md`, regenerated by `backend/scripts/demo_scenarios.py`). Both use the stage-1 illustrative inputs.
Say so on screen: the yellow "Illustrative demo data" banner does this automatically.

## Before the demo

1. `backend`: `python -m uvicorn app.main:app --port 8000` (Atlas or the SQLite fallback; `/health` shows which).
2. `frontend`: `npm run dev` → open the printed URL.
3. Optional: `ANTHROPIC_API_KEY` in `backend/.env` for the live copilot. Without it, show the verifier tests (step 7b).
4. Backup: `docs/screenshots/` contains a screenshot of every step from the automated browser run.

## Live walkthrough (each step verified by `frontend/e2e/workflow.e2e.mjs`)

| # | Action | What to point out | Expected (from `DEMO_RESULTS.md`) |
|---|---|---|---|
| 1 | Landing page | live status: API, database, 11 models, AI | status card from the API |
| 2 | Projects → create project → *Load stage-1 examples A/B/C* → *Evaluate all designs* | requirements shared by all designs; table straight from the backend | A 204.8 Wh, B 204.8 Wh, C 409.6 Wh |
| 3 | Cell selection | data status badge, completeness 6/22, "not provided" fields, what each one blocks | missing values are never filled in |
| 4 | Electrical → *Run* | CC-CV logic, end condition, efficiency; flag "no OCV curve → CV not modelled" | A: 1.4 h charge, 39.06 °C est. peak |
| 5 | Thermal → *Run* and *Run sweep* | the "simplified" label; temperature vs current is non-linear (I²R) | A at 20 A: 46.65 °C (TH-01 FAIL) |
| 6 | Switch the active design to B → BMS & safety → *Run* | EL-01 WARN at the 1C limit; CT-01 max safe current; NOT EVALUATED is not a pass | B: 42.63 °C, EL-01 WARN |
| 7 | Design comparison → *Run* | constraint-first: A misses REQ-03 (1.4 h > 1 h), so B ranks first despite a lower raw score; trade-offs listed | B recommended |
| 7b | AI assistant | Live: Analyst or Optimizer question, then click T-refs to show the engine sources and the verification badge. Offline: show `test_copilot.py` incorrect-claim cases | verified badge or the test table |
| 8 | Engineering report → *Generate* → *Print/PDF* | inputs with source tags → model ids → results → checks → assumptions → limitations | full traceable report |

## Safety note for any physical follow-up

Only supervised, low-voltage (< 60 V DC), fused, temperature-monitored single-cell tests, following the cell
manufacturer's handling instructions. No physical tests have been performed for this project.
