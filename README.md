# BatteryX AI

AI-assisted engineering platform for designing battery energy modules: configure, simulate, check, compare,
explain and report, with every number traceable to its inputs, models, assumptions and data sources.
TELIPORT Season 4, Case Study 2 (Tata Elxsi) · Team Bit Manipulators, Walchand College of Engineering, Sangli.

> All results are **model estimates**, not measurements, and the rule checks are **not a safety certification**.
> Demonstrations use the stage-1 **illustrative** cell (not a real product).

| Folder | What |
|---|---|
| `backend/` | FastAPI engine, AI copilot, databases. See `backend/README.md` |
| `frontend/` | React + Vite + Tailwind UI (13 pages, Recharts, Three.js), including the **Live simulator** (stage-1 BatteryWeave prototype, merged). See `frontend/README.md` |
| `docs/` | technical documentation, audit report, demo scenarios and results, evaluation mapping, screenshots, presentation |

Quick start: see `docs/TECHNICAL_DOCUMENTATION.md` §8.
